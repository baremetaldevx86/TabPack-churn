# T21 — Packed forward-equivalence test design

## Assignment and evidence

Design implementation-ready tests showing homogeneous and heterogeneous packed
forward passes equal independently evaluated MLPs under controlled weights,
inputs, structural masks, and dropout masks. This deliverable is a specification;
the coordinator owns integrating executable tests once the model API is fixed.

Sources read:

- `swarm.md`, Decisions 6–8: pack dimension first, no parameter sharing, reduced
  depth/width/dropout ranges, independent member batches, probability averaging.
- Paper v1, §§3.2–3.3 and §3.6:
  <https://arxiv.org/html/2607.05380v1#S3.SS3>. Hidden blocks are
  Linear–ReLU–Dropout; narrow activations are zero-padded; shallow members skip
  deeper blocks; members can receive different batches and dropout rates.
- `docs/agents/T27.md`, especially tensor contract and coordination questions:
  conceptual logits `[M,B,1]`, parameter independence, width/depth masking, and
  request for explicit heterogeneous cases/tolerances.

No model implementation or executable tests existed during initial inspection.
No official source was imported or executed. Tiny synthetic fixtures below test
algebra only and are unrelated to the Churn dataset.

## Oracle and test adapter contract

Build each oracle from fresh `torch.nn.Linear` modules of its *actual* width and
depth. Do not call packed forward, unpack/export helpers, the repository's own
ordinary-MLP forward, or production mask utilities inside the expected-value
calculation. Otherwise the same bug could appear on both sides. Compare the
ordinary repository MLP separately against this oracle.

Define depth as the count of hidden Linear–ReLU–Dropout blocks. After those
blocks, apply one independent width-to-one linear head, without ReLU, dropout,
or sigmoid. Let `d[m]`, `w[m]`, and `p[m]` describe member `m`. The oracle is:

```python
def independent_forward(layers, head, x, *, training, p, keep):
    h = x
    for layer_index, linear in enumerate(layers):
        h = torch.relu(linear(h))
        if training and p != 0:
            k = keep[layer_index]  # boolean [B, actual_member_width]
            assert k.shape == h.shape
            h = h * k.to(h.dtype) / (1 - p)
    return head(h)  # [B, 1], including when B == 1

expected = torch.stack([
    independent_forward(ref[m].layers, ref[m].head, x_pack[m],
                        training=training, p=specs[m].dropout,
                        keep=keep_by_member[m])
    for m in range(M)
])  # [M, B, 1]
```

The test adapter may translate parameter layout and output representation but
must contain no model math. Construct expected active weights independently,
then copy the same tensors into the corresponding packed slices under
`torch.no_grad()`. Document transposition if packed storage is `[in,out]` rather
than `nn.Linear`'s `[out,in]`. Never derive all expected weights by calling the
implementation's own extraction helper. Check shape *before* value comparisons:
broadcasting must not let `[B]` pass as `[M,B,1]`.

T27 proposes `[M,B,1]`. If T14 chooses `[M,B]`, explicitly assert that raw shape
and add exactly one trailing dimension in the test adapter. Never use bare
`squeeze()`. Every case compares **each member's logits**, not merely the mean,
sigmoid output, AUC, or loss.

## Deterministic fixture recipes

Use CPU float64 initially and no autocast. With zero-based member/layer/row/column
indices, fill an active `nn.Linear` matrix using:

```text
W[m,l,r,c] = (((11*m + 7*l + 3*r + 5*c) mod 23) - 11) / 32
b[m,l,r]   = (((5*m + 3*l + r) mod 11) - 5) / 32
head_weight[m,r] = (((7*m + 3*r) mod 13) - 6) / 16
head_bias[m] = (m - 1) / 8
X[m,b,f] = (((13*m + 5*b + 3*f) mod 19) - 9) / 8
```

These non-symmetric values vary with member, layer, row, and column and include
both signs. Fixed literals below provide a second oracle independent of this
recipe. Also run the small main cases with local generator seeds `7` and `19`,
weights scaled by `0.2`; this broadens coverage without relying on initializers
or perturbing the global RNG. Assert that at least one output per member is
nontrivial and the targeted sensitivity fixtures actually change when their
active data/weights change.

### Hand-checkable signed-logit/dropout fixture

One member, one hidden block, `F=2`, width 2, batch 3:

```text
X = [[-1, 2], [0, 0], [2, -1]]
hidden W = [[1, -2], [-3, 1]], b = [0.5, -0.5]
head W = [[2, -1]], b = [0.25]
ReLU hidden = [[0, 4.5], [0.5, 0], [4.5, 0]]
evaluation logits = [[-4.25], [1.25], [9.25]]
training p = 0.5, keep = [[1, 0], [0, 1], [1, 1]]
controlled training logits = [[0.25], [0.25], [18.25]]
```

The negative evaluation logit catches an accidental output ReLU; the twofold
survivor scale catches missing inverted-dropout scaling. All values in this
fixture are exactly representable in binary floating point.

## Structural and stochastic masking details

**Width masks:** For member width `w < W_max`, poison hidden output rows beyond
`w`, hidden input columns beyond `w`, their biases, and padded output-head
columns. Use finite alternating values such as `+16` and `-8`; repeat with
different signs/magnitudes. Active slices remain byte-for-byte unchanged. A
masked hidden activation must stay zero in padded positions before it can feed
the next active calculation. Include nonzero padded biases; zero padded weights
alone cannot prove the activation mask works. Do not use NaN/Inf poison: a
zero-mask multiplication need not remove NaNs, which would test an unrelated
non-finite contract. Poison only truly inactive coordinates according to the
declared layout, never active feature columns in the first layer.

**Depth masks:** Beyond `d[m]`, the entire hidden block is identity for that
member, including dropout. For a shallow member with positive surviving
activations and `p=0.5`, set deeper-layer keep masks to all zero. Its output must
still equal its one-block oracle. This catches an implementation that skips
only the linear operation but reapplies dropout to the carried representation.
For `p=0`, changing skipped matrices must have no effect, while changing the
last active matrix in a targeted positive-activation fixture must have an effect.

**Dropout control:** A common random seed is insufficient to prove equality:
packed and looped kernels can consume different numbers/orders of random draws.
Use boolean keep masks of shape `[M,B,W_max]` per packed hidden layer and slice
the identical active portions for the independent oracle. Set the `p=0` member's
active keep masks to all ones. For other members a reproducible fixture can use
`keep[m,l,b,h] = ((m + 2*l + b + 3*h) % 4 != 0)`; force one all-dropped sample
and include differing member masks even when rates match. Deterministic masks
test dropout algebra, not whether this pattern samples a Bernoulli distribution.

T14 should provide a narrow way to supply masks in tests, or document a single
RNG-call boundary that can be patched while retaining the production forward
path. A reimplementation of packed forward inside the test does not validate
the production model. If neither seam exists, mark F07 explicitly unimplemented;
evaluation-only agreement does not establish training-mode dropout agreement.

## Assertions, tolerances, and meaningful failures

- Require finite logits, equal shapes and dtypes/devices, then compare the full
  tensor with `torch.testing.assert_close(..., equal_nan=False)`. Report member,
  layer/spec, input mode, mask mode, dtype/device, and maximum absolute error.
- Exact binary fixture: use `rtol=0, atol=0` on CPU. General CPU float64 small
  fixtures: `rtol=1e-10, atol=1e-12`. CPU float32 fixtures: `rtol=1e-5, atol=1e-6`.
- Optional CUDA float32 mirror of F02/F06/F07: start with
  `rtol=1e-4, atol=1e-5`, disable autocast and TF32 for the strict comparison,
  and restore backend precision settings afterward. CUDA absence is an explicit
  optional skip, not a CPU-suite failure. Do not relax tolerances automatically;
  inspect discrepancies before approving a change.
- Mask/order invariants also compare against the original packed result, but
  that does not replace comparison against the independent oracle. Output
  perturbation fixtures must establish a nonzero expected change on the target
  member, avoiding vacuous success behind dead ReLUs.
- A review should verify tests reject: copying member 0's input to every member,
  using one shared weight/bias, omitting width masks, ignoring depth masks,
  applying dropout after skipped blocks, sharing masks, omitting `1/(1-p)`, and
  applying sigmoid/ReLU in the logit head. These are review/mutation targets,
  not changes requested to the production implementation.

Inference aggregation is a separate neighboring check: for member logits
`[0,2]`, compare mean sigmoid `0.6903985389889411`, not sigmoid of mean
`0.7310585786300049`. Forward equivalence alone must not claim optimizer, loss,
RNG distribution/independence, or end-to-end training equivalence.

  requested heterogeneous coverage; the explicit tolerance policy and shape
  adapter above resolve its equivalence-test questions without assuming a
