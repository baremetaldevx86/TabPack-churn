# T14 — Ordinary and packed model implementation design

## Assignment and scope

This note specifies an independently authored ordinary binary MLP and a
heterogeneous packed MLP for the reduced Churn experiment. It is an
implementation/API design and review, not a source patch. The packed module
must preserve the behavior of independent ordinary MLPs while evaluating their
member dimension together. It must work on CPU and CUDA with the agreed
float32 protocol, and it must make width/depth masking observable enough to
test.

The local experiment compares one ordinary MLP, a homogeneous collection of
independent ordinary MLPs, and a reduced heterogeneous **packed TabPack-style**
member pool. The packed name is deliberately qualified: this is not the
official implementation and does not claim the paper's embeddings, Muon
optimizer, pruning, or full evaluation protocol.

## Proposed public API

The coordinator can place these classes in the eventual model module; this
note intentionally does not prescribe a source path while the repository has
no implementation files. Use ordinary `ValueError`/`TypeError` messages for
bad shapes and configurations rather than relying on Python `assert`, because
assertions may be disabled in production.

```python
class OrdinaryMLP(nn.Module):

class PackedMLP(nn.Module):
    def __init__(

        device: torch.device | str | None = None,
        dtype: torch.dtype = torch.float32,
    ) -> None: ...

    def forward(self, x: Tensor) -> Tensor:
        # x [B, input_dim] or per-member x [M, B, input_dim].
        # return [M, B] when output_dim == 1,
        # otherwise [M, B, output_dim].
        ...

    def forward_features(self, x: Tensor) -> Tensor:
        # Optional test/debug API: final hidden representation [M, B, H_max]
        # with inactive width channels exactly zero.
        ...
```

`M = len(depths) = len(widths) = len(dropouts)` must be positive. Require
`input_dim > 0`, `depth >= 1`, `width >= 1`, `output_dim >= 1`, and each
dropout to be finite in `[0, 1)`. The local sampled dropout list `[0, .1,
.2]` therefore has no `p=1` division edge case. Store configuration values
separately from tensor state so serialization is unambiguous; include all
member configurations in the run manifest/checkpoint.

The ordinary model returns logits, not probabilities. Training and evaluation
callers own `BCEWithLogitsLoss`, sigmoid conversion, probability averaging,
and metric precision. Keeping this boundary explicit prevents a sigmoid from
being accidentally applied before the stable logits loss.

## Ordinary MLP semantics

The ordinary model is a conventional sequence of `depth` hidden
`Linear -> ReLU -> Dropout` blocks followed by one independent linear output
head. For binary Churn, the hidden width is constant within one member and
the output head has one logit. A homogeneous ensemble is simply `M` separate
`OrdinaryMLP` instances with separate parameters, dropout draws, optimizer
state, and batch permutations; it is not a call to `PackedMLP` with equal
configuration.

```text
x                         [B, F]
for layer in 0 .. depth-1:
    h = Linear_layer(x)   [B, H]
    h = ReLU(h)
    h = Dropout(p)(h)
logits = output(h)        [B, 1]
return logits.squeeze(-1) [B]
```

Recommended details:

* Use `nn.ModuleList` for hidden blocks and a separate `nn.Linear` head; this
  guarantees every parameter participates in `state_dict` and `.to(device)`.
* Validate rank and final feature dimension at the forward boundary. Reject
  non-floating inputs rather than silently moving/casting data on another
  device; the data pipeline should supply finite float32 tensors.
* Initialize through the framework's standard linear initialization or an
  explicitly documented equivalent. For packed equivalence fixtures, copy
  ordinary active slices into the packed tensors instead of relying on equal
  random seeds, since packed and looped random-number consumption can differ.
* `forward` does not reduce across samples or members. `eval()` disables
  dropout and must produce identical repeated outputs for identical inputs.

## Packed tensor contract

The first dimension is always the member/pack dimension. `B` is batch size,
`F` is the common input feature count, and `H_max = max(widths)`:

```text
ordinary input                  x              [B, F]
broadcast input                x_pack         [M, B, F]
hidden after a packed block                    [M, B, H_max]
binary output logits                            [M, B, 1]
binary return value                             [M, B]
probability average (outside model)              [B]
```

If callers provide `[B,F]`, create `x.unsqueeze(0).expand(M, -1, -1)`. This
is a read-only broadcast view: never write to it in place. If callers provide
`[M,B,F]`, require the leading dimension to equal `M`; this form permits each
member to receive a distinct batch/permutation while preserving the same
model parameters. Do not accept `[B,M,F]` or infer axes from arbitrary rank.

Packed trainable tensors should have a leading member axis and no
cross-member terms:

```text
hidden_weight[layer=0]    [M, H_max, F]
hidden_weight[layer>0]    [M, H_max, H_max]
hidden_bias[layer]         [M, H_max]
output_weight              [M, output_dim, H_max]
output_bias                [M, output_dim]
depths                     [M]             long buffer
widths                     [M]             long buffer
dropouts                   [M]             float buffer
```

The `Parameter` object itself may be one packed allocation, but member slices
must occupy disjoint coordinates and all operations must be diagonal in `M`.
Do not implement a packed member as a wider shared `nn.Linear`: that would
introduce cross-member features and fail the independence contract. Do not
average or sum logits inside `forward`.

## Width and depth masks

Let `width_mask[m,j] = (j < widths[m])`, with shape `[M,H_max]`. At each
active hidden block, the linear output is masked before activation and again
after dropout as a defensive invariant:

```text
z[m,b,j] = sum_i x[m,b,i] * W[layer,m,j,i] + bias[layer,m,j]
z        = z * width_mask[:, None, :]
h        = ReLU(z)
h        = member_dropout(h, dropouts[m])
h        = h * width_mask[:, None, :]
```

For a later block, the previous output mask means columns beyond the member's
actual width are already zero. The implementation may also multiply the
input by the corresponding mask explicitly; this is cheap insurance against
future changes to feature routing. Padded weights need not remain zero: they
cannot affect active outputs when their input columns and output channels are
masked, and their gradients must be zero for active computations. AdamW
decay can still change an unused stored value; tests should check functional
isolation rather than demand that every padded parameter stay numerically
zero.

Depth requires a different operation from width padding. A member with
`depths[m] = d` executes only blocks `0..d-1`; it must not pass through the
remaining blocks and then be reset to zero. For block index `ell`, define
`active = depths > ell`. Select only `active` member indices, evaluate that
block on those members, and scatter the result back while leaving inactive
members' previous hidden representations unchanged. If `active` is empty,
break. This guarantees a depth-1 model's final representation is its first
block output even when another member has three blocks.

The optional `forward_features` result is useful for tests: for every member
`m`, `features[m,:,widths[m]:]` must be exactly zero, and a shallow member's
features must be invariant to perturbations of deeper inactive-layer weights.

## Independently authored packed forward pseudocode

This uses vectorized batched matrix multiplication while selecting active
members for depth. `index_copy`/`torch.where` should be used to avoid unsafe
in-place writes into tensors needed by autograd.

```python
def packed_forward(self, x):
    check_float_rank_and_last_dim(x, expected=self.input_dim)
    if x.ndim == 2:
        x_pack = x.unsqueeze(0).expand(self.member_count, -1, -1)
    elif x.ndim == 3 and x.shape[0] == self.member_count:
        x_pack = x
    else:
        raise ValueError("expected [B,F] or [M,B,F]")

    hidden = None
    for ell in range(self.max_depth):
        active = self.depths > ell                 # [M], on x.device
        if not bool(active.any()):
            break
        idx = torch.nonzero(active, as_tuple=False).flatten()
        x_active = x_pack[idx] if ell == 0 else hidden[idx]
        w = self.hidden_weight[ell][idx]
        bias = self.hidden_bias[ell][idx]
        z = torch.bmm(x_active, w.transpose(1, 2))
        z = z + bias[:, None, :]
        z = z * self.width_mask[idx, None, :].to(z.dtype)
        z = torch.relu(z)
        z = member_dropout(z, self.dropouts[idx], training=self.training)
        z = z * self.width_mask[idx, None, :].to(z.dtype)

        if ell == 0:
            hidden = z.new_zeros((self.member_count, z.shape[1], self.max_width))
        else:
            # Do not assign z into hidden in place; retain an autograd-safe copy.
            full = z.new_zeros((self.member_count, z.shape[1], self.max_width))
            full = full.index_copy(0, idx, z)
            active3 = active[:, None, None]
            hidden = torch.where(active3, full, hidden)
        if ell == 0:
            hidden = hidden.index_copy(0, idx, z)

    if hidden is None:  # defensive; constructor requires depth >= 1
        raise RuntimeError("packed MLP has no active hidden block")
    hidden = hidden * self.width_mask[:, None, :].to(hidden.dtype)
    logits = torch.baddbmm(
        self.output_bias[:, None, :],
        hidden,
        self.output_weight.transpose(1, 2),
    )
    return logits.squeeze(-1) if self.output_dim == 1 else logits
```

The pseudocode's first-block branch intentionally allocates a full hidden
tensor and copies only active members. Since every valid member has depth at
least one, all rows are filled in the normal path. A production implementation
may simplify the all-active case, but must retain the same skip semantics.

`member_dropout` should produce a mask of shape `[A,B,H_max]`, where `A` is
the number of active members, not `[B,H_max]` shared across all members. For
each member, use inverted dropout `mask / (1-p[m])`; reject `p=1`. Generate
random values on `z.device` and in `z.dtype`. A device-local caller-controlled
generator may be accepted as an internal/testing option, but no CPU mask
should be sampled and then copied to CUDA. For exact packed-versus-looped
oracle tests, use `eval()` or `dropout=0`; equal seeds alone do not guarantee
identical random draws.

The output head consumes `[M,B,H_max]` with padded channels already zero. Its
active output is therefore equivalent to an ordinary head with input width
`widths[m]`. Initialize each member's real matrices using the member's actual
fan-in (`F` for block 0, `widths[m]` for later blocks and the output head), not
the padded maximum. Padded coordinates may be initialized deterministically,
but they must never alter active predictions.

## Loss and prediction boundaries

The model returns member logits. The training loop must retain separability:

```python
def packed_bce_loss(logits_M_B, y_B):
    targets = y_B.to(dtype=logits_M_B.dtype).unsqueeze(0)
    targets = targets.expand(logits_M_B.shape[0], -1)
    per_member = F.binary_cross_entropy_with_logits(
        logits_M_B, targets, reduction="none"
    ).mean(dim=1)                         # [M], mean over samples only
    return per_member.sum(), per_member # sum members; expose diagnostics
```

Do not use one global `reduction="mean"` over `[M,B]`: it divides the loss
and gradients by `M`, violating the local protocol and the packed optimizer
oracle. The output ensemble is a separate consumer:

```python
member_probabilities = torch.sigmoid(logits_M_B)  # [M,B]
ensemble_probabilities = member_probabilities[selected].mean(dim=0)  # [B]
```

For final binary metrics, the coordinator may follow T36's documented host
float64 probability accumulation while retaining float32 model training.
Validation AUC and greedy selection must consume only validation predictions;
test evaluation happens after the selected snapshots are frozen.

## Device and dtype portability

The module must be portable through ordinary PyTorch device movement:

1. Construct parameters and buffers with the requested `device` and float32
   `dtype`, or construct on CPU and call `.to(device=device, dtype=dtype)`.
   Never call `.cuda()`, `.cpu()`, or `.to("cuda")` internally.
2. Register `depths`, `widths`, `dropouts`, and any static masks with
   `register_buffer(..., persistent=True)` so `.to(...)` and `state_dict`
   handle them. `depths`/`widths` remain integer buffers; only masks are cast
   to the activation dtype for multiplication.
3. Create `arange`, `zeros`, random dropout masks, and temporary tensors using
   `x.device`/`x.dtype`. Do not rely on the process default device or default
   dtype. Reject mismatched input device/dtype with an actionable error rather
   than silently transferring data.
4. Keep training parameters, gradients, and AdamW state in float32. CPU and
   CUDA outputs should be finite and close within declared tolerances, not
   promised bitwise identical; batched GEMM and reduction order can differ.
5. State-dict round trips must work with `map_location="cpu"`, followed by
   `.to(cuda_device)` when CUDA is available. The state must include member
   configurations/buffers so a checkpoint cannot silently reinterpret packed
   slices under another layout.

The implementation should run with no external model dependency beyond
PyTorch. AMP, Muon, compile-specific kernels, and device-specific custom
operators are outside this reduced module. CUDA availability is conditional;
the CPU path is the required baseline.

## Focused implementation tests

No source or tests existed when this note was drafted, so none were run. The
following bounded tests should be implemented by T21/coordinator after the
module exists.

### Shape and validation tests

* Ordinary `[B,F] -> [B]`; packed `[B,F] -> [M,B]`; packed `[M,B,F] ->
  [M,B]` for binary output. Multiclass/general `output_dim > 1` retains the
  final output axis.
* Reject empty member lists, unequal config lengths, nonpositive dimensions,
  nonintegral/zero depths or widths, dropout outside `[0,1)`, rank-1/rank-4
  input, wrong feature count, wrong packed member count, and device/dtype
  mismatches.
* In `eval()`, repeated calls are identical; `state_dict` save/load preserves
  outputs on the same device. Packed probability averaging is `[B]` and is
  not accidentally an average of logits.

### Independent forward oracle

Create configs such as `depths=[1,3,2]`, `widths=[2,5,3]`, and
`dropouts=[0,0,0]`. Instantiate three ordinary models and one packed model,
copy each ordinary model's active weight/bias coordinates into its packed
member, and compare stacked ordinary logits with packed logits on the same
CPU float32 input. Use `torch.testing.assert_close` with a predeclared
float32 tolerance. Repeat on CUDA only when available. Do not compare random
initializations or dropout-enabled calls.

### Mask and depth isolation

* Inspect `forward_features`: every member's channels from `widths[m]` to
  `H_max` are exactly zero.
* Add a large perturbation to a shallow member's deeper inactive-layer weights;
  its logits and features must not change, while another deeper member may
  change. This catches the invalid “compute all layers then zero at the end”
  implementation.
* Perturb padded input-column weights or padded output-row weights and verify
  active predictions do not change. Check that gradients for padded output
  coordinates are zero for a finite active loss; do not require AdamW-decayed
  stored values to remain zero.
* Perturb member `m`'s active parameters and verify only row `m` of packed
  logits changes. This tests diagonal member routing and catches accidental
  cross-member matrix multiplication.

### Dropout and loss tests

* With all dropout zero, training/eval outputs match. With nonzero rates,
  repeated training calls may differ, but the mask has a member axis and
  padded channels remain zero. Use statistical/shape checks rather than
  assuming every Bernoulli draw differs.
* Compare packed BCE's returned per-member values and gradients to explicit
  `binary_cross_entropy_with_logits(..., reduction="none").mean(dim=1)` and
  `.sum()`. Include unequal member logits and assert it is not the global
  member-and-sample mean.
* Compare one member trained alone to that same member in a larger pack under
  identical copied parameters, data, dropout disabled, and independent
  optimizer state. Other members must not alter its gradient or next update.

### Device/state tests

* Always run a small CPU finite-output/finite-gradient smoke test. If CUDA is
  available, construct on CPU, move the full module and inputs to CUDA, run
  forward/backward, and check all parameters/buffers are on one device.
* Save a CPU state dict, load it into an equivalent packed module, and compare
  outputs. If CUDA is available, load with `map_location="cpu"`, move the
  module, and check shape/finite output; exact CPU/CUDA equality is not a
  requirement.
* Test that width/depth buffers and masks move with `.to(device)`; a CPU
  `arange` or dropout mask left behind should fail this test immediately.
