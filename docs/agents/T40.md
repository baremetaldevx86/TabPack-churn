## Official-versus-local budget

The pinned official plain Churn recipe uses 64 candidates, fixed width 384,
depth 1–4, batch 256, bfloat16 AMP, MuonAdamWPack, base patience 16, ensemble
patience 32 and maximum selection 32. Official Churn selection score is
accuracy. The paper evaluates most TabPack numbers conservatively: one main
selection run, then secondary retraining of selected configurations; its
optimistic alternative repeats the full workflow per seed. Official Table 5
lists batch 128, a separate source/config discrepancy recorded by T1/T6.

The local decision is a transparent **reduced, optimistic, fixed-recipe
workflow comparison**:

- seeds `[0,1,2]`, four base members and maximum four selected snapshots;
- ordinary one-member baseline: depth 2, width 64, dropout .1, AdamW
  `.001/.0001`;
- homogeneous control: four independent copies with the same fixed recipe,
  independent parameters, optimizer state, initialization/dropout streams and
  permutations;
- packed path: four no-sharing heterogeneous members, depth/width/dropout
  choices `[1,2,3]`/`[32,64,96]`/`[0,.1,.2]`, log-uniform lr `[.0003,.003]`,
  weight decay `[1e-6,.001]`, packed AdamW, validation-AUC greedy snapshots;
- common train-fitted preprocessing, per-member batch 256, float32, cap 100,
  patience 16, no embeddings, Muon, pruning or external tuning.

This intentionally changes model count, capacity, optimizer, precision,
selection metric, candidate count, preprocessing and evaluation protocol. It is
not parameter-, FLOP-, wall-clock- or search-opportunity matched. It compares
complete locally specified workflows. No score difference identifies packing,
heterogeneity or selection as a causal factor.

## Fairness controls and observable accounting

Before any real run freeze: dataset/archive/split identity, train-only
preprocessing, target coding, method order, seeds and sampling policy, member
records/stream identities, loss reduction, batch size per member, epoch/patience
convention, validation metric and tie policy, candidate pool semantics, selected
cap, dtype/device, timing boundaries and aggregate formula. Use validation only
for checkpoints/early stopping/greedy choices; freeze all selected snapshots;
then evaluate test once. Report every seed, not the winner, with mean and sample
SD and paired deltas over shared seeds.

Record per seed/method: actual epochs and updates, per-member sample counts,
logical and stored/padded parameter counts, selected snapshot count and unique
member count, validation evaluation/candidate counts, validation AUC, frozen
test AUC/log-loss/accuracy if declared, wall phases, peak resources, device,
threads, precision and failures. One packed optimizer call is not one ordinary
member update; four members process four times the member-example pairs.

For a fair **packing-only** claim, add a separate matched looped-versus-packed
ablation using identical heterogeneous configs, weights, batches, optimizer and
selection. The required three-family comparison does not supply this ablation.
Likewise, a homogeneous-versus-heterogeneous attribution requires fixed
selection and matched capacity; it is outside this requested reduction.

## Disagreement reconciliation

- T16 proposed an empty 0.5 baseline, canonical-key sorting and warm-started
  selection. Decision 9/T3/T23/T53 override it: best singleton always, supplied
  stable pool order, rebuild from scratch and strict outer retention.
- T4/T47 distinguish “optimistic protocol” from validation-score optimism:
  optimistic full reruns may still evaluate test only after a frozen selection.
- T3/T6 establish official Churn accuracy versus local ROC-AUC; local AUC must
  not be placed beside official accuracy without labels.
- T46/T37 establish capacity and timing caveats: packed storage may exceed
  logical parameters, and fit wall includes validation/selection under one
  boundary; do not divide ensemble wall by member count.
- T53's current sampler uses per-run redraw of heterogeneous settings. This
  policy must be recorded; shared member settings across seeds would be a
  different conditional estimand.
