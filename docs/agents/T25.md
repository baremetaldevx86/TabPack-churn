## Correctness contract

`binary_roc_auc` accepts any finite one-dimensional score values, requires both
0 and 1 labels, sorts equal scores into groups, and awards half credit to a
cross-class tie. It rejects empty/mismatched/rank-2/nonbinary/nonfinite input.
`binary_log_loss` accepts finite probabilities in `[0,1]`, allows one observed
class, uses natural logs and a mean reduction, and clips only for loss. Its
default epsilon is `sys.float_info.epsilon == 2**-52`; explicit epsilon must be
representable and satisfy `0 < eps < .5`. Probability averaging is row-wise
before the metric and uses `math.fsum`; no logits or member AUCs are averaged.

Independent exact vectors:

| labels | values | expected |
| --- | --- | ---: |
| `[0,1]` | `[.1,.9]` | AUC 1.0; log-loss `-log(.9)` for corresponding probs |
| `[0,1]` | `[.9,.1]` | AUC 0.0 |
| `[0,1]` | `[.5,.5]` | AUC .5 |
| `[0,1,0,1]` | `[.1,.4,.4,.8]` | AUC .875 |
| `[0,1,0,1]` | `[.5,.5,.5,.5]` | AUC .5 |
| `[0,0,1,1]` | `[.1,.2,.3,.4]` | AUC 1.0 |
| `[0,0,1,1]` | `[.1,.4,.35,.8]` | AUC .75 |
| `[1,1]` | `[.8,.6]` | log-loss `0.3669845875401002` |
| `[0,1]` | `[0,1]` | endpoint loss `-log1p(-2**-52)` |
| `[0,1]` | `[1,0]` | endpoint loss `-log(2**-52)` |

Also assert malformed labels/scores, single-class AUC, out-of-range log-loss
probabilities, invalid eps values (0, negative, .5, NaN, infinity, 1e-300),
constant-score behavior, boolean prediction rejection, and 2-D rejection.
