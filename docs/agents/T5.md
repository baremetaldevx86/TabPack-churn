## Field-by-field comparison

| Setting | Pinned plain TabPack Churn | Local reduced default |
| --- | --- | --- |
| Main/root seeds | Main seed 0; evaluation `n_seeds=5` | Full independent workflows at 0, 1, 2 |
| Base models / selected cap | 64 / 32 | 4 / 4 |
| Width | Fixed 384 | Uniform choice 32, 64, 96 for heterogeneous members |
| Hidden blocks | Integer range 1–4 | Uniform choice 1, 2, 3 |
| Activation | ReLU | ReLU |
| Dropout | Exact declaration `['_tune_', '?uniform', 0.0, 0.0, 0.5]` (optional-zero/uniform form) | Uniform choice 0, .1, .2 |
| AdamW branch lr | Log-uniform .0001–.005 | Log-uniform .0003–.003 |
| Weight decay | Log-uniform .001–1 | Log-uniform .000001–.001 |
| Muon lr | Log-uniform .001–.1 | No Muon |
| Optimizer | `MuonAdamWPack`, `shared_step=true` | Independently implemented packed AdamW; ordinary stock AdamW |
| Precision | `amp_dtype='bfloat16'` | float32, no AMP |
| Batch | 256 per member | 256 per member |
| Epoch cap | `n_epochs=-1`, no positive cap in config | 100 |
| Patience | Base 16; ensemble 32, official stopping after p+1 nonimprovements | 16; runner must document its exact off-by-one convention |
| Online pool | `latest`, prior ensemble included | Prior retained snapshots plus current epoch snapshots |
| Selection score | Dataset metric: Churn accuracy | Validation ROC-AUC |
| Preprocessing | noisy-quantile; extract binary from numeric; convert binary to category; ordinal; cache | Train median + normal quantile; mode + external one-hot; no all-split binary discovery |
| Evaluation protocol | Conservative selected-configuration retraining | Optimistic full-workflow reruns |

The actual optional-dropout mixture probability is not specified by those five
JSON tokens alone; this note preserves the declaration rather than inventing a
uniform discrete distribution or claiming its probability. T9 supplies the
optimizer grouping audit: Muon handles backbone matrices, AdamW handles other
parameters, biases receive zero decay, and there is no learning-rate schedule.

The dagger (`tabpack-cosine`) config adds `CosineEmbeddingsPack`, samples depth
1–3, embedding dimension 8–32 in steps of 4, and embedding init scale .01–10
log-uniform. “Cosine” refers to feature embeddings, not an LR scheduler. The
local recipe omits embeddings entirely.

The ordinary and homogeneous local baseline is depth 2, width 64, dropout .1,
AdamW lr .001 and weight decay .0001, with biases exempt. It is untuned and is
not the paper's tuned MLP, MLP-HPE, SameHP, or TabM baseline.
