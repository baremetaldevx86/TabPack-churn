# T18 — Safe Churn loader and train-only preprocessing design

## Assignment and status

Design the loader, validation, preprocessing API, provenance, and acceptance tests for the reduced Churn experiment. This is an integration specification, not an implemented loader. Only this note and T18's ledger entries are owned by agent-18.

**Recommendation:** require a reviewed, immutable Churn source lock; load its original arrays and split indices without resplitting; fit one preprocessing object on training features only; reuse it across all three methods. Missing or unverifiable canonical data must stop the scientific run before model initialization.

## 1. Canonical source and raw schema

### Reviewed source lock

Proposed version: `churn-source-lock/v1`. Keep the reviewed lock separate from the acquisition receipt generated alongside downloaded files. A receipt that merely hashes arbitrary local files cannot certify canonical origin.

| Field | Required semantics |
| --- | --- |
| `dataset_id`, `origin` | Fixed `churn` and `official_tabpack_archive`; synthetic fixtures have a distinct identity. |
| `reference_code` | Public repository URL and pinned Git SHA above; this is not the local implementation SHA. |
| `source` | Public dataset repository, immutable data revision, archive name, expected size/digest, digest authority, optional observed archive digest. No signed redirect URLs or credentials. |
| `members` | Exact allowlisted consumed relative paths, roles, expected byte sizes/SHA-256, expected array shapes/dtypes or JSON schema. Hash `info.json` as well as arrays. |
| `split_id`, `split_paths` | Canonical `default` split if confirmed by acquisition; exact train/val/test member paths in their original order. |
| `task` | Binary classification; documented 0/1 target mapping with positive-class meaning; score `roc-auc`. Never infer mapping from holdouts. |
| `feature_schema` | Ordered block/column identities, declared feature types and declared missing tokens; source identifiers/target explicitly excluded. |
| `expected_counts` | Confirmed total and train/val/test row counts, block widths; require full partition if the canonical indices establish one. |

Unconfirmed fields may be `null` in a research draft, but runtime validation rejects an incomplete lock. A manual file-placement route is valid only if the bytes verify against the same approved lock. A different dataset revision requires a reviewed new lock, not an automatic refresh.

### Raw storage contract

The following layout follows inspected upstream loader conventions; make it an exact allowlist only after verifying archive contents:

```text
info.json
y.npy                         # (N,), int64, values exactly 0 and 1
x_num.npy                     # (N, D_num), float32, if declared present
x_cat.npy                     # (N, D_cat), int64 or fixed-width Unicode, if present
x_bin.npy                     # (N, D_bin), float32, only if present in canonical source
splits/default/train.npy      # (N_train,), int32
splits/default/val.npy         # (N_val,), int32
splits/default/test.npy        # (N_test,), int32
```

The API uses `val` consistently; display labels may say “validation.” Optional feature blocks are optional only when the approved schema says so. Do not silently omit a missing expected block or auto-discover extra `.npy` files. Do not treat a legacy split-file format as equivalent without a separately reviewed conversion and preserved byte/split provenance.

### Validation order

1. Check the approved lock is complete, source identity is accepted, and every required local member exists. The loader performs no network request or extraction.
2. Resolve each allowlisted path under the explicit data root; reject traversal, external symlink/junction targets, unexpected file types, duplicate logical paths, and partial download files. Bound metadata/header and total array sizes before allocation; derive normal sizes from the lock and enforce an independent safety ceiling.
3. Check member byte sizes/hashes against the lock. Parse exactly the verified bytes or a captured immutable snapshot, avoiding a hash-then-reopen race. Small Churn members can be held as bounded byte buffers. Use `np.load(..., allow_pickle=False)`; reject object/structured/complex dtypes, malformed NPY, oversized dimensions, and inconsistent payload sizes. Never enable pickle to accommodate a failing categorical file.
4. Validate `info.json` task metadata and the declared feature/target schema. Feature names may be stable block/index names if original names are unavailable; do not fabricate semantic names. Reject mismatched ranks, widths, dtypes, or row counts. Numeric NaN is allowed as declared missingness; infinity is invalid. Categorical missingness uses only declared tokens; empty strings and the literal `"nan"` are not automatically missing. Validate explicit binary blocks against their declared domain.
5. Validate every split index before indexing: integer vector, nonempty, in `[0, N)`, unique within split, pairwise disjoint, expected counts, and exact canonical coverage. Preserve original index order. No shuffling, sorting, row deletion, deduplication, or resplitting here.
6. Validate target is rank one, nonmissing, and exactly `{0, 1}`; train and both evaluation splits require both classes for the chosen ROC-AUC protocol. Fail instead of repairing a split or changing metrics. Data/schema checks on test labels are permitted, but test labels must not reach fitting or selection.
7. Return copied/read-only split arrays with original source row indices. Retain indices as internal lineage, outside model features. Identical feature values across distinct source rows are not evidence of index leakage; report them only as an audit observation and preserve the canonical split.

## 2. Proposed API

Names below are proposals for the coordinator's implementation, not existing imports:

```python
load_churn(root: Path, *, source_lock: ChurnSourceLock) -> RawChurn

fit_preprocessor(
    train: FeatureBlockSet,
    *,
    schema: FeatureSchema,
    config: PreprocessConfig,
) -> FittedPreprocessor

transform_features(
    fitted: FittedPreprocessor,
    features: FeatureBlockSet,
) -> Float32Matrix

prepare_fit_data(raw: RawChurn, *, config: PreprocessConfig) -> FitData

prepare_test_data(
    raw: RawChurn,
    *,
    fitted: FittedPreprocessor,
    selection_freeze: FrozenSelectionReceipt,
) -> EvaluationData
```

- `FeatureBlockSet`: ordered numeric/categorical blocks, schema, no target or row-ID columns. Declared binary blocks become categorical features under a fixed schema rule, preserving train-only most-frequent imputation. Do not discover new binary columns by looking across splits.
- `RawChurn`: train/val/test feature blocks and labels, read-only source indices, validated source lock, consumed-file inventory, and dataset identity hash.
- `FitData`: transformed train/val matrices, unchanged train/val targets, internal split lineage, shared ordered feature names, fitted object, learned-state metadata/fingerprint. The trainer receives this view rather than the raw all-split container.
- `EvaluationData`: frozen-transform test matrix and original labels, accessible to final evaluation after the selection-freeze event. A receipt is an orchestration guard, not a security boundary; control which objects the trainer/selector receive.
- `FittedPreprocessor`: immutable after fitting; `transform` cannot extend vocabularies, recompute imputers, drop columns, or update quantiles. Its fitting API accepts features only—neither train nor holdout targets are needed.

All methods use the same transformed training/validation data and fitted state for a comparison seed. Prefer a fixed preprocessing seed/config shared across model seeds as well; model initialization/batch seeds are independent. If preprocessing is intentionally randomized by seed, the same realized transform must still be shared across methods and its identity recorded.

## 3. Train-only preprocessing specification

Proposed reduced default `preprocess/v1`:

| Step | Fit on training features | Transform every split with frozen state |
| --- | --- | --- |
| Numeric missingness | Per-column finite-value median | Replace only declared missing values by that median. |
| Numeric normalization | `QuantileTransformer(output_distribution="normal", n_quantiles=min(1000, n_train), subsample=n_train, random_state=0)` on imputed train | Apply its fixed quantiles, including standard out-of-range behavior. No split-specific normalization. |
| Categorical missingness | Most-frequent nonmissing value per column; deterministic tie break using declared typed ordering | Missing maps to that stored mode. |
| Categorical encoding | Train-only vocabulary; one-hot, `handle_unknown="ignore"`, `drop=None`, dense float32 | Unknown nonmissing categories map to an all-zero block; they are not missing and are not imputed to the mode. |
| Assembly | Numeric block then categorical blocks in declared column/vocabulary order | Preserve rows and equal feature width; return contiguous finite float32. |

`subsample=n_train` uses all training rows and avoids a version-dependent random subsample default. Record effective parameters and exact scikit-learn/NumPy versions. No injected noise is proposed for this reduced pipeline. The coordinator can deliberately choose another train-only quantile policy, but must version and document it rather than inherit upstream defaults accidentally.

Reject an entirely missing training column with `ALL_MISSING_TRAIN_COLUMN` and its logical feature name: a train median/mode is undefined. Do not fill from holdouts or silently let an imputer drop the feature. Preserve constant observed columns and their fixed transformer behavior; no holdout-driven feature pruning. Zero-width absent blocks are supported, but an entirely empty feature schema fails. Fit categorical columns with homogeneous declared types; do not stringify arbitrary objects or collapse integer and string values. Check the final float32 conversion for nonfinite values rather than masking them with `nan_to_num`.

This intentionally differs from official noisy quantiles, numeric binary extraction, ordinal preprocessing at the loader boundary, and NaN-to-zero repair. T8's audit clarifies that the official model subsequently one-hot encodes those ordinal categories with an all-zero unknown-category block; external one-hot encoding is therefore a placement change, not evidence that the official model uses continuous ordinal category values. The proposed pipeline satisfies the reduced project's explicit train-only median/quantile and mode/one-hot decisions; it must not be described as paper-identical preprocessing.

## 4. Provenance, learned state, and cache identity

Adopt T48's `python-json-v1` canonical JSON and sorted `data-files.json` inventory (`path`, `role`, `size_bytes`, `sha256`). Include every consumed raw feature, target, metadata, and split-index file. Whole-file byte hashes preserve source row order; archive identity supplements, rather than replaces, member hashes. Dataset identity excludes local absolute paths and retrieval timestamps.

Expose train-fitted state for T24 and checkpoint integration:

```text
schema_version: preprocess-state/v1
fit_split: train
fit_row_count
config: complete effective parameters and missing-value rules
input_schema / ordered_output_feature_names
numeric: medians, quantiles, reference probabilities, effective quantile count
categorical: modes, ordered typed categories, output block offsets
software: numpy / scipy / scikit-learn versions
learned_state_sha256
```

Fingerprint the canonical finite learned-state payload excluding the fingerprint field itself. Keep **learned-state identity separate from full dataset identity**: changing only held-out features or labels must not change this fingerprint. Store original train source-index lineage separately from learned state, and do not feed row IDs into fit. A preprocessing artifact identity may additionally bind fitted state to the approved data/split identity for resume compatibility.

For this small experiment, prefer recomputing preprocessing to adding a disk cache. If a cache is later required, its key includes source member hashes, split identity, preprocessing code/config version, feature schema, and dependency versions. Never key only by path/basename/config or deserialize upstream pickle caches. Loading restored learned state validates dimensions, schema/version, finite values, category uniqueness/order, config, and source compatibility. Persist JSON plus non-object arrays if state exceeds practical JSON size; fingerprint the exact canonical payload/inventory.

Following T48, public run manifests contain whole-file/split hashes and aggregate schema/counts, not source row IDs, row-level hashes, or customer records. Internal source-index vectors support leakage tests without publication. Full fitted state may expose feature values; retain it as a controlled local artifact, while ordinary public provenance can link its digest and a schema summary.

## 5. Failure and orchestration contract

Use a typed `ChurnDataError(code, logical_path, summary, remediation)` rather than assertions or broad “try another dataset” recovery. The real-data CLI exits nonzero and records no successful scientific score on these failures:

| Code | Trigger / actionable response |
| --- | --- |
| `CANONICAL_SOURCE_UNAVAILABLE` | No approved immutable source/member manifest; acquisition must complete or be reviewed first. |
| `DATA_MISSING` | Missing data root/member; show logical missing filenames and direct the user to the project's explicit fetch/manual-placement workflow. |
| `DATA_INTEGRITY_MISMATCH` | Expected size/digest mismatch; list logical member and expected/observed digest, then require verified reacquisition. |
| `DATA_SCHEMA_INVALID` | Wrong task, shape, dtype, binary target/domain, nonfinite input, or unsafe NPY; identify the violated invariant. |
| `SPLIT_INVALID` | Invalid/duplicate/overlapping/incomplete indices, wrong canonical split, or ROC-AUC class support failure. |
| `ALL_MISSING_TRAIN_COLUMN` | Median/mode cannot be learned; identify feature and stop. |
| `PREPROCESS_NONFINITE` | Fitted/converted feature output is nonfinite; retain diagnostic metadata without publishing rows. |
| `PREPROCESS_STATE_MISMATCH` | Attempted inference/resume with a different schema/config/data/transform identity. |

Example user-facing message: `DATA_MISSING: canonical Churn is unavailable; missing y.npy and splits/default/train.npy. Complete the project's verified data acquisition step and retry. No experiment was run.` The CLI owner supplies the real command name; none exists at the time of this design.

No import-time downloads, automatic source replacement, data generation, or implicit split repair. The downloader owns network/extraction and atomic publication; the loader consumes only a complete verified directory. Validation/test influence is limited to schema validity checks and fixed transformation, never choosing normalization, feature types, imputers, vocabularies, or thresholds. Selection uses validation predictions/labels; test transformation/inference/evaluation occurs after the chosen model/ensemble is frozen.

## 6. Acceptance tests

All unit tests are tiny/offline. Synthetic fixtures use lower-level feature/split APIs or injected acquisition; they never pass the canonical-loader production gate as Churn.

1. **Canonical success:** temporary verified member fixture plus explicit test-only lock exercises member hashes, schemas, original index order, source-index lineage, immutable arrays, and inventory digest. Separately run a real-data integration check against the approved production lock when available.
2. **Fail-closed acquisition:** missing root/member, partial file, incomplete lock, checksum mutation, and an unrelated valid-looking Churn dataset all raise the exact typed failure before fitting/model creation; acquisition/network fallback is never invoked by the loader.
3. **Safe parsing/schema:** object NPY, rank mismatch, feature/target length mismatch, infinity, invalid target, unexpected required block, traversal, and external link fixtures fail deterministically without pickle or out-of-root reads.
4. **Split isolation:** duplicate, negative, out-of-range, overlapping, missing-row, and wrong-length indices fail. A reordered canonical split fails its byte hash; a test-only split fixture verifies accepted original ordering is preserved. Equal feature values at distinct valid indices remain distinct rows.
5. **Holdout metamorphism (T24):** fix training features and replace validation/test numeric/category sentinels. Learned-state fingerprint, medians, quantiles, categories, output names/width, and transformed training features remain identical. Run through the data-preparation orchestration as well as the low-level fitter so accidental concatenation is caught.
6. **Missing/unknown semantics:** holdout missing numeric equals the transformation of the stored train median; missing category maps to train mode; unknown category block is all zero. Verify mode ties, all-missing train error, constant columns, and absence of an optional block.
7. **Frozen state/label independence:** transforming holdouts in either order leaves learned state unchanged. Changing any labels without changing features leaves preprocessing unchanged. Trainer/selector spies receive no test labels and test-evaluation spies observe selection freeze first.
8. **Output/replay:** shapes, row counts/order, finite float32, feature names, and per-block offsets agree for every split; fit twice in the pinned environment yields the same state fingerprint. Save/load state must replay transformations with documented numerical tolerance.
9. **Provenance identity:** mutate a source byte or split order and data identity changes/rejects; move identical files to a different directory and identity remains unchanged. Mutate a held-out fixture and full data identity changes while learned-state fingerprint stays fixed. Resume rejects a swapped fitted-state identity.
