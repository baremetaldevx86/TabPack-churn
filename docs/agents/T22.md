## Acceptance claim and independent oracle

For each member, logical parameter and step, compare its active parameter values, first moment, second moment and update count with a separate ordinary AdamW optimizer operating on independently allocated leaf parameters. Check **after every step**, not just at the final step. Match supported options exactly: learning rate, weight decay, betas, epsilon and parameter groups. Default reference options are `amsgrad=False`, `maximize=False`, `foreach=False`, `fused=False`; run in eager mode without autocast or gradient scaling.

The reference optimizers must never call the packed optimizer, packed loss helper or packed update equations. Create all starting values once as explicit tensors; copy those values into both paths with independent `detach().clone()` storage. Use a test-local, explicit member/parameter map rather than trusting production export code as the only mapping oracle. Rectangular weights and unequal widths help expose a mistaken transpose/slice.

For an updated logical parameter, standard AdamW has:

```text
t <- t + 1
m <- beta1 * m + (1 - beta1) * g
v <- beta2 * v + (1 - beta2) * g**2
m_hat = m / (1 - beta1**t)
v_hat = v / (1 - beta2**t)
theta <- theta * (1 - lr * wd) - lr * m_hat / (sqrt(v_hat) + eps)
```

Weight decay does not enter either moment. A genuine `grad=None` skips the entire update, including decay, moments and the counter. An all-zero gradient is an update: decay still acts, moments decay and the counter advances. If only some parameters of a member lack gradients, counters are logically **per parameter per member**, not necessarily one per member or one global step. A scalar counter is equivalent only when all represented parameters always update together.

## Fixtures

### F1: optimizer-only, asymmetric packed parameters

- Primary fixture: `M=3`, logical weight shape `(2,5)`, bias shape `(5,)`; packed shapes `(3,2,5)` and `(3,5)`. Include shape `(M,)` for scalar member parameters if the public API supports it.
- Member hyperparameters: `lr=[0.01,0.003,0.02]`, `wd=[0.0,0.1,0.2]`; shared `betas=(0.9,0.999)`, `eps=1e-8`. These deliberately magnified test values expose wrong broadcasting/decay without long runs. Also include the provisional production-scale lr/wd values in one float32 replay.
- For flattened coordinate `j=0,...,n-1` and zero-based member `m`, initialize `theta[m,j] = 0.25*(m+1) + 0.05*(j+1)*(-1)**j`. Give the bias a different offset so parameter-order swaps cannot pass.
- Base gradients: `G[m,j] = (-1)**(m+j)*(m+1)*(j+1)/10`; set `G[m,0]=0`, `G[m,1]=(-1)**m*1e-9`. For steps 1–7 use `G`, `-0.3*G+0.02`, all zeros, `2*G-0.05`, `-G`, `0.1*G+0.03`, `G`. Construct a separate bias sequence using a different offset. Values are fixed and shared by value only between oracle and packed paths.
- Replay the core one-step and seven-step cases with `M=1` using the first lr/wd pair; include `M=4` by appending `lr=.007`, `wd=.05` for the provisional experiment count. A separate square `(M,M)` packed parameter is an adversarial fixture for wrong-but-broadcastable axes, rather than the only test shape.
- Compare moments in their logical active regions even if production state is stored in a different packed layout. Validate member and parameter identities before numerical comparisons; do not zip unordered dictionaries.

### F2: tiny real-gradient model bridge

Use independent `nn.Linear` layers with dropout disabled, input dimension 3, a hidden activation matching the eventual model, output dimension 1, and fixed copied weights. Homogeneous widths `[2,2,2]` establish a simple bridge; heterogeneous widths `[2,4,3]` and depths `[1,2,3]` exercise the actual model representation once T14 defines it.

Use a fixed six-row CPU tensor `X = arange(18).reshape(6,3)/10 - 0.8` and labels `[0,1,0,1,1,0]`. Provide explicit member-specific mini-batches of size 3 over three updates: for member `m` at step `t=0,1,2`, take the first three indices from a cyclic shift of `[0,1,2,3,4,5]` by `m+2*t`. The independent path receives exactly the same indices for that member. This fixture tests optimizer equivalence, not randomness quality.

Before backward, compare corresponding logits and per-member BCE means. Backward the **sum** of those means in the packed path and each member's mean in the independent path. Compare gradients before stepping, then compare parameters and state after every update and logits on the complete six-row tensor. Zero gradients between updates in both paths. Avoid exact-zero activation prevalues where practical, so a nonsmooth activation boundary does not obscure a mapping failure.

### Padding and inactivity are separate concepts

A width/depth padding slot is not a logical parameter. A temporarily inactive member is a real parameter set with a paused history. A real parameter with zero gradients still updates. Tests must not conflate these three states.

For padding, initialize canonical zeros and verify the representation's documented invariant. If arbitrary finite padding values are valid, use distinct finite sentinels in a second copy to demonstrate that changing inactive storage cannot affect active outputs/updates; do not inject NaNs because `0 * NaN` makes this a different numerical test. If canonical zero padding is required, record that precondition and test only valid inputs. A masked zero gradient alone does not freeze nonzero padding against decoupled decay; preserving arbitrary sentinels requires explicit masking of the complete update.

For partial inactivity, a single tensor cannot express `.grad=None` for only one member slice. T15 must expose an activity mask with skip semantics, group truly independent parameters, or explicitly restrict the interface to lockstep updates. If members can pause independently, a global step counter alone is insufficient. If only per-member masks exist, arbitrary per-parameter missing-gradient equivalence is outside that restricted API and must not be claimed.

## Tolerances and diagnostic quality

- Primary injected-gradient oracle: CPU float64, initial candidate `rtol=1e-11`, `atol=1e-13` for parameters and moments. Tiny-gradient moment coordinates need a targeted scaled-relative comparison or an appropriately much smaller absolute bound, so zero moments cannot pass merely because of the generic `atol`.
- CPU float32 injected-gradient candidate: `rtol=2e-5`, `atol=2e-7`; compare **update deltas** as well as full parameters, so a small lr/decay bug cannot hide under a large initial parameter's relative allowance. Use targeted relative checks for small moments and assert that deliberately nonzero expected moments remain nonzero.
- For the real-gradient bridge, float64 candidate `rtol=1e-9`, `atol=1e-11`; float32 candidate `rtol=2e-5`, `atol=2e-6`. CUDA may need `rtol=1e-4`, `atol=1e-6` for short trajectories with matmul precision/TF32 set explicitly and identically. These are proposed starting bounds, not measured implementation tolerances; investigate failures before broadening them.
- Counters, member identities, supported group options, shape/dtype and skip/no-cross-member invariants are exact. Require finite tensors before comparison. Compare optimizer logical state on an agreed device rather than assuming Torch and custom state counter devices match.
- Report failing `(device, dtype, step, member_id, parameter_name, component)` plus maximum absolute/relative error. Preserve exact fixture values in failure output; never compare only final loss or averaged ensemble output.
- Assert initial value equivalence and oracle/packed memory independence before updates. Packed members may validly occupy disjoint slices of the same backing allocation; equal backing-storage pointers alone do not prove parameter overlap. Mutation-isolation checks are more useful than rejecting all shared allocations.

## Why one weight comparison is insufficient

For ordinary gradients, scaling all gradients by a constant scales Adam's first and second moments together, making the adaptive update nearly scale-invariant when epsilon is small. Thus averaging losses across members can produce very similar first-step weights despite violating the agreed objective. O12 compares **raw gradients**, O01/O02 compare **moments**, and O14 gives epsilon a visible role. A negative-control test should replace the packed member sum with a mean in the test fixture and confirm that gradient/moment assertions detect the intentional error. Other useful test-local faults are broadcasting member 0's lr to every member, adding wd to gradients and incrementing a skipped counter; the appropriate oracle assertions should fail clearly.
