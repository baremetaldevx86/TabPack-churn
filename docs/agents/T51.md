## Evidence read and coordination resolved

Read `swarm.md` first and read the complete notes `T14`, `T15`, `T21`, `T22`,
`T33`, `T36`, and `T46`; also read the introduction of `T27`. These notes cite
paper v1 <https://arxiv.org/html/2607.05380v1> and the pinned official revision
`05a89e21b955f12de84889d662e15ca534019aaa`. This integration relied on the
reviewed contracts and stock PyTorch oracles, not execution of reference code.

- **T14 / T21:** binary outputs are `[B]` and `[M,B]`; general output retains
  `output_dim`. The packed forward supports shared `[B,F]` and member-specific
  `[M,B,F]`. Weight storage follows `nn.Linear`'s `[out,in]` convention with a
  leading member axis. Explicit boolean dropout keep masks are available through
  `dropout_masks=`; ignored in evaluation mode. Zero-probability members ignore
  supplied drop masks. Width padding is inert for the finite poison fixtures;
  absent depth blocks are strictly skipped including dropout.
- **T15 / T22:** optimizer ownership masks preserve padded values and moments;
  absent depth rows have zero counters. Each parameter/member has its own
  int64 step counter and parameter-shaped moment pair. `grad=None`, a zero
  gradient, an inactive member, and nonexistent padding have distinct behavior.
  Per-member learning rates, decay, both betas, and epsilon are supported.
- **T33:** packed BCE returns sample means and their **sum**, including short
  batches and singleton batches. Distinct `[M,B]` labels follow distinct member
  batches. Tests compare raw gradients directly, not merely Adam updates, and
  compare the same member alone versus inside a larger pack.
- **T36:** default parameters/training inputs are float32, float64 supports
  strict oracles, loss uses stable BCE-with-logits, logits have no output
  activation, and input device/dtype mismatches are rejected. Metric precision
  and run-level finite diagnostics belong to the caller. Optional CUDA tests
  compare same-device references; they do not claim CPU/CUDA bitwise identity.
- **T46:** this is **depth-indexed rectangular padding**, allocating maxima of
  the supplied member widths/depths. It selects active rows before each hidden
  batched matrix multiply, still computes padded width work, and retains dense
  parameter/moment storage. `logical_parameter_count` excludes nonexistent
  coordinates; `stored_parameter_count` is actual parameter tensor inventory.

The ledger's integration override is implemented: **all biases have zero
decay** when callers use the model-aware factory/groups. Snapshot helpers
produce compact weights-only independent ordinary modules. Optimizer
state-dict tests verify the optimizer API; they do not add a training-resume
CLI or change the weights-only experiment checkpoint policy.

## Public integration contract

```python
from tabpack.models import OrdinaryMLP, PackedMLP, packed_bce_loss
from tabpack.optim import PackedAdamW, make_optimizer

single = OrdinaryMLP(input_dim, depth=2, width=64, dropout=0.1)
single_optimizer = make_optimizer(single, lr=0.001, weight_decay=0.0001)

pack = PackedMLP(
    input_dim,
    depths=[1, 2, 3, 2],
    widths=[32, 64, 96, 32],
    dropouts=[0.0, 0.1, 0.2, 0.1],
).to(device)
optimizer = make_optimizer(
    pack,
    lr=[0.001, 0.0005, 0.002, 0.0015],
    weight_decay=[0.0001, 0.0002, 0.00005, 0.0001],
)
optimizer.zero_grad(set_to_none=True)
loss, member_losses = packed_bce_loss(pack(x_M_B_F), y_M_B)
loss.backward()
optimizer.step()
snapshot = pack.extract_member(member_index).eval()
```

- `PackedMLP` accepts the T14 keyword constructor: `input_dim`, `depths`,
  `widths`, `dropouts`, optional `output_dim=1`, `device`, and `dtype`.
- Each member has a constant hidden width; depth counts hidden blocks. No
  feature embeddings, normalization, sigmoid head, or cross-member operation.
- Ordinary hidden layers are `.layers` (alias `.hidden_layers`) and `.head`.
  Packed tensors are `.hidden_weight`, `.hidden_bias` (plural aliases also
  available), `.output_weight`, and `.output_bias`.
- `forward_features(...)` returns `[M,B,max_width]`, with padded channels zero.
- `packed_bce_loss` (alias `packed_bce_with_logits_loss`) returns
  `(summed_training_loss, per_member_means)`. It accepts shared `[B]` targets or
  packed `[M,B]` targets, also packed `[M,B,1]` logits/targets. Inputs must have
  nonempty member/batch dimensions and finite binary targets. Features and
  targets must already be on the intended model device.
- `pack.parameter_masks()` returns `{Parameter: boolean_same_shape_tensor}`.
  `pack.optimizer_groups(weight_decay)` creates groups carrying those masks and
  zero bias decay. Build optimizer **after** moving the model to the device.
- `PackedAdamW(pack.parameters(), ...)` is a generic unmasked packed-tensor
  optimizer. For model training, use `make_optimizer` or `optimizer_groups`
  so structural masks and the bias policy are included.
- `PackedAdamW.step(active=[True, False, ...])` pauses all parameters of the
  indicated members, preserving state/decay/counters. Optional group
  `member_mask` supports per-parameter member absence; group `mask` is full
  parameter-shaped ownership and such groups contain one parameter.
- Hyperparameters can be scalar or length-M lists/tuples/tensors. `betas` is a
  pair whose entries may each be member vectors. Learning rate zero preserves
  parameters but still advances moments/counters when a gradient exists.
- `pack.copy_member_from(index, ordinary)` copies active weights.
  `PackedMLP.from_members(ordinary_members)` packs copied weights in order and
  is useful with caller-managed member initialization seeds.
  `extract_member(index)` produces detached-in-storage parameter snapshots.
  `from_members` and `extract_member` preserve the CPU RNG stream and do not
  use the CUDA RNG stream while constructing snapshot modules.
- Native dropout draws have a member dimension; exact stochastic trajectories
  across different pack sizes/layouts are not promised. Use the explicit
  per-layer `[M,B,max_width]` boolean keep-mask seam for matched oracle draws.
- The optimizer is eager AdamW, with no AMSGrad, sparse gradients, AMP,
  graph-capture, fused mode, pruning, or cross-member gradient clipping.
  Hyperparameter vectors are expanded over trailing axes, never the last axis.
