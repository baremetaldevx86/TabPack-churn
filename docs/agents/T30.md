## Canonical storage and validation

The local source lock and loader expect `info.json`, `y.npy`, a verified subset
of `x_num.npy`, `x_cat.npy`, `x_bin.npy`, and ordered
`splits/default/{train,val,test}.npy`. The actual feature block presence,
shapes, dtypes, member hashes and feature names must be read from the fully
verified archive; the allowlist is not a fabricated inventory. Split indices are
int32, unique, disjoint, in-range and complete, preserving source order. Each
split must contain both classes.

The loader retains an adjacent complete archive as its trust anchor. It checks
full archive bytes/size before deriving member digests and comparing the local
extraction. It rejects alternate revisions, mutable `main`, arbitrary local
receipts, unsafe tar members, links/special files, malformed NPY/object arrays,
and silent IBM Telco or synthetic substitutes. The synthetic seam is explicitly
`synthetic_smoke_v1` and cannot satisfy `dataset_id=churn`.

## Preprocessing and leakage boundary

Local `preprocess-state/v1` fits numeric median and normal-output quantile state
on train only (`n_quantiles=min(1000,n_train)`, all train rows,
`random_state=0` by default). Categories use train mode, typed deterministic
tie-breaking and dense float32 one-hot with unknown categories ignored. Explicit
binary blocks join categorical processing; numeric binary discovery across all
splits is intentionally not copied from upstream. The output is contiguous
finite float32 with numeric then categorical blocks. Learned-state fingerprints
exclude holdout features and all labels; full data identity includes consumed
file bytes and split roles.

No target semantic remapping, split regeneration, test-driven preprocessing,
threshold choice, or label-based source repair is allowed. Test transformation
may be prepared but test prediction/evaluation occurs only after selection is
frozen.
